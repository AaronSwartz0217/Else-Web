# 达克效应 · 分镜与时间线（勇士与魔王）

> 本文件＝**这支片的分镜事实来源**。改任何一拍先改这里，再改 `scenes/*.html` 里的 `SCENES` 表。
> 成片规格：35.0s / 1920×1080 / 30fps / 0.75× 采样（**1 输出秒 = 22.5 源帧**）→ 源帧 **788** → 输出帧 **1051**。
> 主题：达克效应（越不懂越自信）。外壳：复古 RPG「勇士与魔王」。
> 硬规矩：出片前必跑 `inspect.js` 闸门；交付必交封面图；**每个 3D 场景必须支持 `?roam=1`**（用 `共享资源/roam.js`）。

## 0 风格总纲（手段统一、配色各不同）

| 维度 | 规定 |
|---|---|
| **统一的手段** | ① 环境＝**伪 3D 场景**（石柱 / 巨峰 / 巨树 / 沙丘 / 城堡 / 废墟）；② 人物与恶龙＝**2D 彩色剪影**，锚在世界坐标上的 billboard（漫游时位置正确）；③ 字幕＝**复古 RPG 对话框**（粗边框＋打字机＋闪烁 ▼）；④ 全片叠一层轻 CRT（用 `共享资源/webgl_post.js`，逐场调参，不叠重噪）；⑤ 合成器 BGM 贯穿。 |
| **各场不同** | 配色、气氛、粒子、机位节奏**逐场独立**：金红黑 / 蓝白银 / 绿紫暗金 / 红橙黑 / 黑红紫 / 白金黑 / 暗红银 / 灰蓝暗红 / 金白黑 / 暗金灰。 |
| **人物硬约束** | **无脸、无五官**；只取**半身 / 背影 / 侧面**；永远是**剪影**（填色＋一道本场强调色的轮廓光），不做正面大特写。 |
| **复古 RPG 质感** | 2px 棋盘抖动渐变（16bit 味）· 剪影外描 1–2px 暗边 · 对话框 / 数值条 / 章节标签用等宽＋方角 · 火光 / 雷电 / 岩浆按 8bit 光栅感处理。 |
| **BGM** | 合成器（脉冲主旋律 + 琶音 + 锯齿贝斯 + 噪声明暗鼓）；**关键节点突然全静音**（每个勇士死亡、龙崩解），静音 0.5–0.9s 后只留环境声。 |

## 2 分镜（每拍：源帧 / 画面 / 字幕 / 声音）

### A ① 王国·宝座 　0–113　色调：金、红、黑

- 3D 殿堂：石柱高耸（透视列柱）、火盆橙红（每盆一簇 8bit 火焰 + 地面反光）、地面反光（湿石地镜面）。
- 国王 2D 剪影**端坐高处**（侧面/半身），**王冠尖利**；四个勇士 2D 剪影**单膝跪地、背影、无脸**，一字排开。
- 节拍：0–34 建立（推轨 + 火盆亮起）→ 34–62 国王抬手 → 62–78 **一道白光射向远方**（横向白光带扫过）→ 78–100 四勇士起身、转身、走出殿门（背影渐远、门缝光）→ 100–113 收在空殿。
- 字幕（对话框）：`国王下令：讨伐恶龙。`
- 声音：庄严合成器进行曲（低音管风琴式 pad + 脉冲主旋律）；34 抬手的低频上扬；78 起身一记鼓；113 硬切入下一场。

### B ② 行进　113–248

- **② 雪山　113–158　色调：蓝、白、银灰**：3D 巨峰（多层三角山脊 + 雪线），风雪粒子横飞，冰面折射冷光（斜向光带）。四个勇士 2D 剪影**依次掠过、全深黑、全背影**、朝**同一方向**走去。
  - 字幕：`四个勇士，出发了。`
- **③ 森林　158–203　色调：绿、紫、暗金**：3D 巨树（粗树干 + 盘错树根如网），雾气弥漫（多层雾带），萤火虫光点飘浮（确定性飘浮）。剪影穿过树影，**光斑打在背上**（树隙投影）。
  - 字幕：`穿过森林。`
- **④ 荒漠　203–248　色调：红、橙、黑**：3D 沙丘（多层曲面沙脊），**红月低垂**，枯骨散落（牛骨/头骨剪影），热浪扭曲空气（横向抖动波）。剪影踩过沙丘，**风沙抹去脚印**（脚印出现→被吹散）。
  - 字幕：`穿过荒漠。`
- 声音：一段连贯的行进合成器主题（脉冲琶音），每 2 秒一次小鼓过渡；转场处各一声硬切（踩雪 / 落叶 / 风沙）。

### C ⑤ 城堡远景 　248–293　色调：黑、红、暗紫

- 3D 黑色城堡**巨大、压在画面中央**；门缝透出红光（线性红光 + 地面红反射）；岩浆裂纹（地面裂纹发光）；乌鸦盘旋（几只 2D 剪影绕圈）；雷电闪动（全屏瞬亮 2–3 次，2D 锯齿闪电）。
- 四个勇士 2D 剪影站在门前，**小如尘埃**（约 20px 高）。
- 字幕：`抵达城堡。`
- 声音：低压合成器 + 雷声（噪声爆）+ 乌鸦；一段不安的持续音。

### C ⑥ 第一个勇士·龙炎 　293–383　色调：白、金、黑

- 2D 勇士**举起整个王国最强大的宝剑**（剑身反光刺眼：一道对角高光扫过）。
- 节拍：293–320 举剑（剑身高光扫过）→ 320–344 他冲向 2D 恶龙（侧身奔跑剪影放大）→ 344–362 **龙炎喷涌**（橙白火柱吞屏）→ 362–372 **白光吞没一切**（全屏过曝白）→ 372–383 白光退去，**剑落地**（剑插地）、**人消失**。
- 字幕：`他以为剑够快。` → `他不知道龙根本不给他靠近的机会。`
- 声音：**344 起全切（突然静音）**，只留火焰的低频轰；372 一记金属落地。

### C ⑦ 第二个勇士·利爪 　383–473　色调：暗红、黑、银

- 2D 勇士**侧身翻滚**（侧面连续翻滚剪影），避开火焰（火墙从画外扫过），动作精准。
- 节拍：383–410 翻滚避火（火墙横扫）→ 410–432 逼近龙腹 → 432–452 **利爪从天而降，黑影覆盖画面**（自上而下压来的巨大爪影）→ 452–473 消失（画面只余黑影与银灰冷光）。
- 字幕：`他躲过了火，` → `却没想过龙还有爪子。`
- 声音：**432 起全切**，一记下坠风压。

### C ⑧ 第三个勇士·对话 　473–563　色调：灰蓝、暗红

- 2D 勇士在城门口**徘徊、来回踱步**（左右走动的剪影，步伐迟缓）。
- 节拍：473–505 踱步（脚步 + 灰蓝冷光）→ 505–528 **他放下武器**（剑插地/落地）→ 528–548 **张嘴，试图与龙交流**（侧面**半身**，仅剪影张口动作，无五官）→ 548–563 **龙低头，红光一闪 → 消失**。
- 字幕：`他想了很久，` → `却选了最蠢的办法。`
- 声音：踱脚步声 + 低沉环境音；548 红光一闪时**全切**。

### C ⑨ 第四个勇士·尖刺 　563–675　色调：金、白、黑

- 2D 勇士**快速冲入城堡**；**不举剑、不徘徊**。
- 节拍：563–590 疾冲（侧面奔跑，速度线）→ 590–608 **火焰喷来、他侧身**（擦身而过的火）→ 608–626 **利爪落下、他翻滚**（爪影擦过，翻滚剪影）→ 626–648 **冲到龙背后**（镜头绕到龙背后）→ 648–662 **伸手，拔出龙背上那根尖刺**（金色尖刺被拔出、龙体一僵）→ 662–675 **龙崩解成黑烟与光点**。
- 字幕：`他冲到龙背后，` → `拔出了那根刺。`
- 声音：疾冲的合成器加速；648 拔刺**全切** + 一记"咔"；662 崩解（黑烟噪声 + 光点上扬）。

### D ⑩ 废墟之上 　675–788　色调：暗金、深红、灰

- 3D 废墟；**画面拉远**（相机后撤 + 抬升成俯视）。
- 第四个勇士 2D 剪影站在**三具尸体与龙的残骸之上**，**他极小**；脚下三具勇士轮廓 + 巨龙残躯**堆成一座小山**；**远处又一批勇士正朝这里走来**（一排小剪影自地平线走来）。
- 字幕叠加：
  - `他赢，不是因为他最能打。` → `是因为他看见了那根刺。`
  - 标题：**达克效应**
  - 偏下小字：`越不懂，越觉得自己什么都懂。越懂，越知道自己不知道什么。`
  - `剧终`
- 声音：收束的合成器长音 → 点题处只留极轻 pad，末帧淡出。

## 4 出片自检清单

1. `node test_render.js` —— 每场取**极值帧**（不止均匀撒点）：A 的国王抬手/白光；B 的三段各一张 + 脚印被吹散；C 的雷闪/白光吞没/爪影覆盖/红光一闪/崩解；D 的俯视全景。
2. 每个场景 `?roam=1` **自己先走一圈**：柱距、山脊、树根、沙丘、城堡门、废墟堆的机位与遮挡。
3. `node render.js`（1051 帧）→ `node inspect.js frames 60`（**闸门不过不出片**；期望表按源帧分段，注意 `frames/` 存的是输出帧）。
4. `python gen_audio.py`（看逐拍 RMS：三段静音处必须塌到 ≈0）→ `node build.js` → `node cover.js`。
